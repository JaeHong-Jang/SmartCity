# SmartCity

브라우저에서 여러 사람이 **실시간으로 함께 짓는** Cities: Skylines 스타일 3D 스마트시티 시뮬레이터.
도로·교차로·신호·횡단보도·과속방지턱을 직접 설계하고, 3D 스튜디오에서 블록을 쌓아 건물을 만들어 배치하면, 시민이 집에서 나와 보도를 걷고 횡단보도를 건너 출근하며, 차량은 차선 규칙·신호·보행자 양보에 따라 움직입니다.
최종 목표는 돌발 상황(사고·도로 폐쇄·재난) 발생 시 도시 전체의 대응을 시뮬레이션하는 것입니다.

## 빠른 시작
```bash
npm install
npm run dev        # 협업 서버(:8780) + 웹(:5280)
# 브라우저: http://localhost:5280/?room=main  (같은 room 으로 접속하면 함께 건설)
```
서버 없이 혼자 쓰려면 `?offline=1`을 붙여 **오프라인 단독 모드**로 엽니다(아래 문제 해결 참고).

**AI 건설 도우미(선택)**: `apps/server/.env.example`을 `apps/server/.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣은 뒤 서버를 다시 시작합니다. 키는 서버에만 있고 브라우저로는 보내지 않습니다. 기본 모델은 `claude-sonnet-5-5`이고 `SC_AI_MODEL`로 바꿀 수 있습니다. 키 없이 흐름만 보려면 `SC_AI_FAKE=1`(각본 도우미)로 시작합니다.

| 명령 | 설명 |
|---|---|
| `npm test` | 전체 단위·통합 테스트 |
| `npm run typecheck` | 전체 타입체크 |
| `npm run build` | 타입체크 + 웹 빌드 |
| `npm run e2e` | Playwright 브라우저 스모크 테스트 |

## 문제 해결
- **"서버에 연결하는 중…" 화면**: 서버(:8780)가 꺼져 있거나 재시작 중입니다. 자동으로 다시 시도하며(간격 최대 10초) 연결되면 화면이 사라지고 서버의 도시가 열립니다. 서버 도시 대신 브라우저에 저장된 다른 도시를 띄우는 일은 없습니다. 열린 채 응답이 없는 연결도 기한(10초부터 시도마다 두 배, 최대 60초) 뒤 끊고 다시 시도합니다. 화면에 "도시 파일을 읽을 수 없습니다"가 보이면 서버의 그 방 파일(체크포인트 또는 명령 로그)이 손상된 것이므로 아래 복구 방법을 따릅니다(다른 방은 정상 동작).
- **오프라인 단독 모드**: 연결 화면의 [오프라인 단독 모드로 열기] 또는 `?offline=1`. 상단의 붉은 배너가 사라지지 않으며, 도시는 이 브라우저에만(`localStorage`의 `smartcity:offline:<방>`) 저장되고 서버의 같은 이름 방과 **별개**입니다. 예전 키 `smartcity:local:<방>`의 도시는 새 키로 복사되며 원본 키는 지우지 않습니다. 저장본을 읽을 수 없으면(손상·더 새로운 버전) 빈 도시로 열지 않고 오류 화면에서 [원본 내보내기]만 제공하며, 그 키에는 아무것도 쓰지 않습니다. 서버 방에 접속했을 때 이 브라우저에 같은 이름의 다른 오프라인 도시가 있으면 알림이 뜨고, [JSON으로 내보내기] 후 상단 **가져오기**로 새 방에 넣을 수 있습니다(자동 병합 없음).
- **서버 재연결 중(노란 배너)**: 이미 열려 있던 서버 도시는 오프라인으로 바뀌지 않고 연결을 기다립니다. 그동안 편집은 막힙니다.
- **백업과 복구**: 서버는 체크포인트를 쓸 때마다 이전 파일을 `apps/server/data/backups/<방>/<시각>.json`에 남깁니다(최근 30개 + 최근 14일은 하루 1개, 시각은 UTC이고 `:` 대신 `-`, 같은 밀리초면 `-1`·`-2` 접미사, 덮어쓰지 않음). 복구는 서버를 끄고 → 원하는 백업 파일을 `apps/server/data/<방>.json`으로 **복사**하고 → 같은 방의 `<방>.log.jsonl`을 비우거나 지운 뒤(백업 이후의 편집 기록이라 섞이면 안 됨) → 서버를 켭니다. 읽을 수 없는 파일은 `data/<방>.corrupt-<시각>.json`으로 사본이 남습니다.

## 조작
| 입력 | 동작 |
|---|---|
| 빈 땅 좌클릭 드래그 · 휠 클릭 드래그 · Shift+우클릭 드래그 · WASD | 화면 이동 |
| 우클릭 드래그 / Q·E | 회전 |
| 휠 / R·F | 확대·축소 |
| 1~9 | 선택 · 도로 · 건물 · 철거 · 버스 노선 · 도로 폐쇄 · 필지 · 교통 시설 · 조닝 |
| G | 격자 스냅 8m → 4m → 2m → 1m → 끔 |
| C (도로) · P (필지) | 곡선 도로 · 다각형 필지 |
| 건물·교차점·필지 꼭짓점 드래그 (선택 도구) | 이동 (도로 근처에서는 도로에 맞춰 정렬, Shift = 자유 배치) |
| `[` `]` / Shift+휠 | 선택한 건물 회전 (Alt = 1°) |
| Alt+드래그 · I · Delete | 건물 복제 · 스포이드 · 철거 |
| Esc / 우클릭(움직이지 않고 짧게) | 취소 |

**3D 건물 스튜디오(건물 탭 → 3D 스튜디오)**: 클릭으로 2m 블록 쌓기, 드래그로 사각 채우기, 노란 화살표로 층 올리기, 덩어리 칠하기(팔레트·재질·용도), 장식 14종(발코니·차양·간판·나무·태양광·헬리패드 등), 좌우/앞뒤 대칭, 되돌리기(Ctrl+Z), 주사위(주택·상가·유리 오피스·친환경 타워·한옥풍).
- **시점**: 상단 **앞·오른쪽·뒤·왼쪽·위·전체** 버튼, Q/E(Shift = 90°)·방향키 회전, V 시점 순환, 숫자패드(Blender식), Home/F 맞춤. 회전 = 우클릭 드래그 또는 Alt+드래그(트랙패드), 이동 = 휠 버튼 드래그 또는 Shift+우클릭 드래그, 확대 = 휠. 터치는 두 손가락 회전·확대, 세 손가락 이동.
- **지우기**: Shift+클릭 또는 짧은 우클릭. **Tab** = 패널 접기, **?** = 조작 안내.
**교통 시설(8)**: 구간 횡단보도(비신호/신호), 과속방지턱(20km/h 통과), 어린이보호구역(30km/h, 비신호 횡단보도 앞 일시정지). 교차로 속성에서 신호/비신호/모든 방향 일시정지, 다리별 자동 횡단보도. 보행 신호는 WALK 7초 + 점멸(횡단 길이 ÷ 1.0m/s).
**시민 생활**: 주거 30m²당 1명이 출근(07~09시)·근무·상점·귀가 일과를 따라 움직입니다. 화면 상단 시계는 실제 1초 = 게임 10초이고, 밤에는 사람이 있는 건물 창문이 켜집니다.
- **이동 수단**: 걷기(1km 이하), 자가용, 버스 중에서 고릅니다. 버스는 근처 정류장에서 직행 노선이 있으면 예상 시간을 비교해 탑니다.
- **버스 승하차**: 정류장에 줄을 서서 기다리고, 정원(버스 기본 40명, 차량 편집기에서 변경)만큼 탑니다. 승하차 인원에 따라 정차 시간이 늘어납니다(10~40초).
- **확인 위치**: 정류장 옆 배지와 노선 패널에서 대기·탑승 인원을 봅니다.
**보행 전용 신호(교차로 속성)**: 신호 교차로(3~4지)에서 켜면 차량 위상 뒤에 모든 방향 보행 위상이 붙습니다. 이때 차량은 모두 적색이고, 차량 위상 중에는 횡단보도가 열리지 않습니다.
**조닝(9)**: 도로를 따라 드래그해 주거·상업·업무 구역을 칠합니다.
- **필지 생성**: 칠한 쪽 도로변에 8m 셀 단위 필지가 생깁니다. 깊이는 `[` `]` 키로 1~4칸을 고릅니다. 지우기 모드도 있습니다.
- **자동 성장**: 도시 수요(상단 **성장 수요** 막대)가 있으면 서버가 5초마다 빈 필지에 건물을 자동으로 세웁니다. 끄려면 막대 패널의 **자동 성장** 체크를 해제합니다.
- **도로와의 관계**: 도로를 자동 필지 위로 그으면 겹치는 필지와 자동 건물이 빨갛게 표시되고, 함께 정리됩니다.
**AI 건설 도우미(오른쪽 AI 탭)**: "시청 앞에 빨간 벽돌 카페 3채 지어줘"처럼 말하면 AI가 도시를 살펴보고 건물을 설계·배치하거나 도로변을 조닝해 **제안**합니다.
- **미리보기**: 반투명 고스트로 확인합니다.
- **적용**: **적용**을 누르면 내 명령으로 반영되어 다른 참여자에게 보입니다.
- **충돌 처리**: 그사이 다른 사람이 같은 자리를 쓰면 해당 항목은 주황색으로 표시되고 **가능한 항목만 적용**할 수 있습니다.
- **위치 표시**: 적용하면 카메라가 그곳으로 이동하고 새 건물·도로가 반짝인 뒤 빛기둥이 남습니다. **최근 적용** 목록의 **보기**로 다시 찾아가고 **확인**으로 빛기둥을 끕니다. AI가 만든 설계에는 **AI** 배지가 붙습니다.
- **사진으로 건물 만들기**: **이미지 첨부**(또는 붙여넣기·끌어다 놓기)로 사진·그림을 최대 2장 넣으면 층수·덩어리·지붕·색·외벽 스타일을 보고 2m 블록 설계로 근사합니다(사진과 똑같지는 않음). 스튜디오에서 이어서 고칠 수 있습니다.
- **도로**: "여기서 북쪽으로 도로 깔아줘"처럼 요청하면 기존 도로에 연결되는 도로를 제안합니다. 도로 한 건은 통째로 적용되거나 통째로 거부되고, 건물·조닝 필지를 가로지르는 도로는 만들지 않습니다.
- **할 수 없는 일**: 철거와 기존 도로 변경은 하지 않습니다. 되돌리려면 철거 도구로 지웁니다.

**시뮬레이터(상단 버튼)**: 지금 도시의 **사본**을 내 브라우저에서만 돌립니다(다른 참여자·서버에는 영향 없음, 사본에서는 공유 도시 편집이 잠깁니다). 준비 운행(게임 10분) 뒤 사건을 일으킵니다.
- **사건**: 도로 통제(도로 클릭), 사고(차선 위치 클릭), 행사·수요 급증(건물 클릭 — 인원·유입·체류·유출 시간). 목록에서 **보기**·**종료**.
- **스마트 대응**: 켜면 정보를 받는 차량(기본 70%)이 사건 구간을 피해 경로를 다시 찾습니다. 첫 사건 전에만 바꿀 수 있습니다.
- **ON/OFF 비교 실행**: 같은 사본·같은 사건·같은 수요로 반대 정책을 따로 돌려 완료 통행·평균 통행시간·정체 길이·경로 없음+출발 대기·재탐색 수를 같은 시간축 그래프로 비교합니다(준비 운행 이후 기준). 값은 보정 전 게임 모델이며, 대응이 항상 더 낫지는 않습니다.

**다양성**: 조닝 성장 건물은 용도·크기별 변형 24종에서 고르고 자동 성장 건물마다 외벽 톤이 조금씩 다릅니다. 기본 승용차는 세단·SUV·해치백·밴·소형트럭·택시 6종과 여러 색으로 그려집니다(직접 편집한 차종은 편집한 모양 그대로).
**건물 설계 정밀 모드(건물 탭)**: 격자 칠하기(1/2/4m)로 평면을 그리고, 매스를 위에 쌓고, 매스별 용도(주상복합)·외관(격자창/띠창/커튼월/필로티)·스마트 설비(태양광·녹색지붕·EV 충전·센서·드론 포트)를 정합니다. 미래형 프리셋 8종 제공.
**도시 구조 설계**: 필지에 용도지역을 지정하면 건폐율·용적률·높이·후퇴 거리를 자동 검사해 주황 배지로 알려줍니다. 상단 **도시 현황**에서 인구·일자리·RCI·에너지·탄소를 봅니다.

## 구조
```
packages/shared   도시 문서 스키마, Command, applyCommand, 프로토콜, 도로 플래너
packages/sim      결정적 교통 시뮬레이션 (차선 그래프, A*, IDM, 예약 교차로, 신호, 버스)
apps/server       실시간 협업 서버 (명령 시퀀싱, 프레즌스, 로그+체크포인트 영속화)
apps/web          Three.js 3D 편집기 (도구, 에디터, 인스턴싱, 시뮬 워커)
harness/          오케스트라 팀 하네스 (역할, 워크플로, 템플릿, 실행 스크립트)
docs/             아키텍처, ADR, 조사 보고서, 로드맵
```
