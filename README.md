# SmartCity

브라우저에서 여러 사람이 **실시간으로 함께 짓는** Cities: Skylines 스타일 3D 스마트시티 시뮬레이터.
도로·교차로·신호·횡단보도·과속방지턱을 직접 설계하고, 3D 스튜디오에서 블록을 쌓아 건물을 만들어 배치하면, 시민이 집에서 나와 보도를 걷고 횡단보도를 건너 출근하며, 차량은 차선 규칙·신호·보행자 양보에 따라 움직입니다.
최종 목표는 돌발 상황(사고·도로 폐쇄·재난) 발생 시 도시 전체의 대응을 시뮬레이션하는 것입니다.

## 빠른 시작
```bash
npm install
npm run dev        # 협업 서버(:8780) + 웹(:5280)
# 브라우저: http://localhost:5280/?room=main  (같은 room 으로 접속하면 함께 건설)
```
서버 없이 웹만 실행하면 자동으로 **단독 모드**(브라우저 저장)로 동작합니다.

| 명령 | 설명 |
|---|---|
| `npm test` | 전체 단위·통합 테스트 |
| `npm run typecheck` | 전체 타입체크 |
| `npm run build` | 타입체크 + 웹 빌드 |
| `npm run e2e` | Playwright 브라우저 스모크 테스트 |

## 조작
| 입력 | 동작 |
|---|---|
| 빈 땅 좌클릭 드래그 · 우클릭 드래그 · WASD | 화면 이동 |
| 휠 클릭 드래그 / Q·E | 회전 |
| 휠 / R·F | 확대·축소 |
| 1~8 | 선택 · 도로 · 건물 · 철거 · 버스 노선 · 도로 폐쇄 · 필지 · 교통 시설 |
| G | 격자 스냅 8m → 4m → 2m → 1m → 끔 |
| C (도로) · P (필지) | 곡선 도로 · 다각형 필지 |
| 건물·교차점·필지 꼭짓점 드래그 (선택 도구) | 이동 (도로 근처에서는 도로에 맞춰 정렬, Shift = 자유 배치) |
| `[` `]` / Shift+휠 | 선택한 건물 회전 (Alt = 1°) |
| Alt+드래그 · I · Delete | 건물 복제 · 스포이드 · 철거 |
| Esc / 우클릭 | 취소 |

**3D 건물 스튜디오(건물 탭 → 3D 스튜디오)**: 클릭으로 2m 블록 쌓기, 드래그로 사각 채우기, 노란 화살표로 층 올리기, 덩어리 칠하기(팔레트·재질·용도), 장식 14종(발코니·차양·간판·나무·태양광·헬리패드 등), 좌우/앞뒤 대칭, 되돌리기(Ctrl+Z), 주사위(주택·상가·유리 오피스·친환경 타워·한옥풍). 우드래그 = 회전, 우클릭 = 지우기.
**교통 시설(8)**: 구간 횡단보도(비신호/신호), 과속방지턱(20km/h 통과), 어린이보호구역(30km/h, 비신호 횡단보도 앞 일시정지). 교차로 속성에서 신호/비신호/모든 방향 일시정지, 다리별 자동 횡단보도. 보행 신호는 WALK 7초 + 점멸(횡단 길이 ÷ 1.0m/s).
**시민 생활**: 주거 30m²당 1명이 출근(07~09시)·근무·상점·귀가 일과를 따라 걷거나(1km 이하) 차를 탑니다. 화면 상단 시계(실제 1초 = 게임 10초), 밤에는 사람이 있는 건물 창문이 켜집니다.
**건물 설계 정밀 모드(건물 탭)**: 격자 칠하기(1/2/4m)로 평면을 그리고, 매스를 위에 쌓고, 매스별 용도(주상복합)·외관(격자창/띠창/커튼월/필로티)·스마트 설비(태양광·녹색지붕·EV 충전·센서·드론 포트)를 정합니다. 미래형 프리셋 8종 제공.
**도시 구조 설계**: 필지에 용도지역을 지정하면 건폐율·용적률·높이·후퇴 거리를 자동 검사해 주황 배지로 알려줍니다. 상단 **도시 현황**에서 인구·일자리·RCI·에너지·탄소를 봅니다.

## 구조
```
packages/shared   도시 문서 스키마, Command, applyCommand, 프로토콜, 도로 플래너
packages/sim      결정적 교통 시뮬레이션 (차선 그래프, A*, IDM, 예약 교차로, 신호, 버스)
apps/server       실시간 협업 서버 (명령 시퀀싱, 프레즌스, 로그+체크포인트 영속화)
apps/web          Three.js 3D 편집기 (도구, 에디터, 인스턴싱, 시뮬 워커)
harness/          오케스트라 팀 하네스 (역할, 워크플로, 템플릿, 실행 스크립트)
docs/             아키텍처, ADR, 조사 보고서, 로드맵
```
