# ADR 0002: 룸 영속화 = 추가 전용 명령 로그 + 원자적 체크포인트
- 상태: Accepted · 날짜: 2026-10-23

## 결정
- 명령이 적용되면 브로드캐스트 **전에** `data/<room>.log.jsonl`에 `{seq, cmd}` 한 줄을 동기 append.
- 200개 명령 또는 30초마다 체크포인트: `data/<room>.json.tmp`에 `{schema:1, seq, doc}` 기록 → `rename`으로 원자 교체 → 로그 비우기.
- 로드: 체크포인트 + `seq`가 더 큰 로그 줄 재생. 깨진 마지막 줄은 무시(부분 기록).
- 룸 ID는 `^[a-z0-9-]{1,32}$`만 허용 → 경로 탈출 차단.

## 결과
프로세스가 응답 직후 죽어도 승인된 편집은 로그에 남는다. DB는 다중 서버가 필요해질 때(Phase 3) 도입.
