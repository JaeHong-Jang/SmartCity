# ADR 0003: 도로 = 편집용 node/segment + 실행용 lane/connector
- 상태: Accepted · 날짜: 2026-10-23

## 결정
- 문서: `nodes`, `segments`(직선 또는 2차 베지어 `control`), 사용자 정의 `roadTypes`.
- 실행: `compileNetwork(doc)` → 방향·차선별 `Lane`(호 길이 표), 노드별 `Connector`(3차 베지어), 충돌표. 렌더러도 같은 결과를 사용(시각과 시뮬 일치).
- 도로 그리기: `planRoad()`가 스냅(노드 > 기존 도로 > 8m 그리드) → 연결·교차 지점 분할 → 하나의 batch.
- 다차선: 주행 중 차선 변경은 Phase 2(MOBIL). MVP는 **차선 단위 A*로 끝까지 유효한 차선 경로**를 보장하고, 교차로·연속 노드에서 직진 시 인접 차선으로 넘어가는 **차선 이동 커넥터**(비용 +1s)를 둬서 차선 재분배. 경로 비용에 차선 대기열 길이를 반영.
- 곡선 위 위치는 항상 호 길이(s)로 다룬다. 베지어 t를 거리로 쓰지 않는다.

## 고려했으나 기각
- 방향당 1차선으로 축소(Astra 안): 사용자가 실제 도로 설계를 요구 → 다차선 유지, 대신 위 완화책.
- 정수 mm 좌표(Sol 안): Phase 1 교통은 클라이언트별 미리보기라 불필요. Phase 3 서버 권위 전환 시 재검토.
