# ADR 0004: 교차로 = 신호 위상 + 예약 기반 진입 허가
- 상태: Accepted · 날짜: 2026-10-23

## 결정
- 정지선 근처 선두 차량이 커넥터 진입을 요청. 허가 조건:
  1. 신호 노드면 접근로가 녹색(황색·전적색 중 신규 허가 없음).
  2. 충돌 커넥터에 점유·허가 차량 없음. 충돌 = 같은 노드 커넥터 중 폴리라인 최소 거리 < 2.5m(차폭 반영) 또는 같은 진출 차선. 같은 진입 차선 공유는 제외.
  3. 진출 차선 빈 공간 ≥ min(차량 길이 + 2m, 진출 차선 길이) — 이미 허가된 차량 몫을 빼고 **원자적으로 예약**.
- 예약은 차량 **후미**가 커넥터를 벗어날 때 해제.
- 우선순위: 같은 녹색 안에서 직진·우회전 > 좌회전·U턴(비보호 좌회전 양보). 좌회전은 충돌하는 직진/우회전 요청이 대기 중이면 허가하지 않는다. 같은 우선순위 안에서는 도착 틱 → 차량 id.
- 자동 신호: degree ≥ 3, 마주보는 접근로 쌍 위상, green 20s / yellow 3s / allRed 2s. 사용자가 위상 묶음·녹색 시간·오프셋 편집.
- 비신호(`uncontrolled`): FCFS + 위 충돌·공간 규칙.
- "그리드락 방지"의 보장 범위는 **교차로 내부 막힘(꼬리물기) 방지**까지. 도시 규모 순환 교착은 60s 정체 감지로 관측·보고(제거 수 집계).

## 후속
보호 좌회전 위상, 감응 신호, 긴급차량 우선(황색·전적색 생략 금지), 적응형(Max-Pressure) 신호.

## council 의견 요약
Astra #3·#5, Sol "피해야 할 함정"(앞부분 기준 해제, 중복 출구 예약) 반영.
