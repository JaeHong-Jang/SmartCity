# ADR 0007: Phase 2a 건설 고도화 범위와 계약
- 상태: Accepted · 날짜: 2026-10-23 · 결정자: Opus (council: Astra, Argon)
- 제안서: [`../architecture/phase2a-construction.md`](../architecture/phase2a-construction.md)

## 맥락
사용자 요구: 클릭으로 이동, 세분화 격자에 직접 설치, 커스텀 건물 고도화, 시뮬레이션 게임 수준. 조사: [03](../research/03-grids-building-tools-survey.md), [04](../research/04-urban-planning-smart-buildings.md). council 두 리뷰 모두 “범위 과다 → 분할”.

## 결정 (Phase 2a)
1. **조작**: 선택 도구에서 클릭/드래그를 5px 임계값으로 구분. 빈 땅 드래그 = 카메라 팬, 건물 드래그 = 이동, `[` `]`/Shift+휠 = 회전(휠 줌 차단), Alt+드래그 = 복제, `I` = 스포이드, Delete = 철거. 노드 드래그 = `node.move`, 연결 도로 실시간 미리보기. 드래그 중에는 로컬 미리보기만, 놓을 때 명령 1개.
2. **충돌 정책 (shared에서 서버도 동일 판정)**
   - 하드 차단: 건물의 도로 침범(정확한 선분-다각형 거리 판정), 맵 경계, 다른 도로와 새 교차를 만드는 `node.move`, 필지 간 중첩, 같은 건물 안 볼륨의 체적 중첩.
   - 경고만(주황): 건폐율·용적률·높이·후퇴·용도 불일치.
3. **격자**: 스냅 8/4/2/1m/끔(개인 UI 상태), `G` 순환으로 통일. 1·2m 격자는 커서 주변 원형 마스크로만 표시. 도로 정렬 시 로컬 안내 격자 표시.
4. **필지**: `Parcel{polygon, zone, regulation}`. 건물 귀속은 앵커점 포함 규칙(결정적). 건폐율·용적률은 필지 전체 합계.
5. **건물 설계 계약**: 볼륨 `footprint`는 **구멍 없는 단순 직교 다각형, 꼭짓점 ≤ 32, 건물 로컬 좌표(offset 미적용)**. 셀은 편집 표현일 뿐 저장하지 않음. 다각형 볼륨의 지붕은 평지붕. `use`(복합용도), `facade`, `smart`(지붕 면적 예산) 추가. `BuildingType.rev`를 서버가 증가시키고, 편집기는 `expectedRev`로 저장 → 불일치 시 거부(초안 유지).
6. **렌더링**: 건물 설계(타입)별로 볼륨을 하나의 지오메트리로 굽고(벽 UV·층고·외관을 정점 속성으로) 타입별 `InstancedMesh`. 타입 수만큼 드로우콜 — 성능 예산은 실측 후 청크 병합 검토.
7. **지표**: shared `designStats(doc)` = 문서 기준 설계 지표(인구·일자리·RCI 설계 균형·에너지·탄소·규제 위반). 교통 VKT 등 실행 지표는 sim에서 받아 web에서 조합하고 “참여자별 미리보기”로 표시.
8. **수요**: sim 통행 발생·도착 가중치를 용도별 연면적(`buildingMetrics.areaByUse`)으로.
9. **협업 UX**: 다른 사용자가 선택·편집 중인 객체에 색 외곽선+이름 배지.

## Phase 2b로 미룸
전용 3D 스튜디오(푸시/풀 기즈모), 도로 부착 조닝 셀 + 자동 성장(서버 결정적 틱), 되돌리기/다시하기, 다중 선택, 연속 배치, 중정·자유각 평면, 필지 자동 분할, 일조 사선.

## council 의견 요약
- Astra: 하위 호환·재생 경로(→ `normalizeDoc`, docToCommands), 다각형 제약, UI/서버 판정 일치, 노드 이동 위상, 필지 중첩·집계, 면적 중복, 정적/실행 지표 분리, 동시 수정 revision → 모두 반영.
- Argon: 입력 충돌(임계값·휠), 파사드 셰이더(정점 속성), 기즈모·노드 미리보기, 미세 격자 모아레, 복제·스포이드, 경고/차단 2단계, 피어 선택 표시 → 반영. 3D 스튜디오는 2a-2로 분리.
