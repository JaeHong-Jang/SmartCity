# ADR 0008: Phase 2b — 건물 스튜디오, 시민 보행 생활, 거리 교통 시설

- 상태: Accepted · 날짜: 2026-10-23 · 결정자: Opus (council: Astra, Argon)
- 제안서: [`../architecture/phase2b-life-streets-studio.md`](../architecture/phase2b-life-streets-studio.md)
- 조사: [05](../research/05-creative-building-tools.md), [06](../research/06-pedestrians-traffic-calming.md), [07](../research/07-citizens-street-rendering-oss.md)
- council 원문: `harness/runs/20261023-184540-phase2b/{astra,argon}.md` (두 리뷰 모두 approve-with-changes)

## 맥락
사용자 요구는 세 가지다.
1. 건물 만들기가 어렵고 창의적으로 만들기 어렵다.
2. 사람이 집에서 나와 실제로 이동하는 모습이 보여야 한다.
3. 횡단보도, 과속방지턱 등 교통 요소를 모두 갖춰야 한다.

## 결정

### 1. 건물 스튜디오
- **편집 단위:** 3D 블록(2m × 2m × 1층), 4m 큰 브러시.
- **저장 형식:** 기존 `BuildingPart` 직교 볼륨(`voxelsToParts`). 셀 원본은 저장하지 않는다(ADR 0007 §5 유지).
- **파츠 상한:** 16 → **48**. 스튜디오에 예산 게이지를 둔다. 최악 입력(48 파츠 × 32 꼭짓점) 검증 시간을 테스트로 측정한다.
- **재열기:** `partsToVoxels`의 손실 판정은 꼭짓점이 격자 위에 있는지와 층고가 섞였는지로 한다. 면적만 같은 위치 이동도 손실로 잡는다. 손실이 있으면 원본을 보존하고 경고와 함께 변환 사본을 편집하거나 정밀 모드(기존 에디터)를 쓴다.
- **prop:** `BuildingType.props ≤ 64`. 종류는 고정 enum이고 프리미티브로 렌더한다. 서버는 파츠 평면 bbox ± 2m 안, 높이는 최고 높이 + 6m 이하만 허용한다. prop은 면적 지표와 도로 침범 판정에서 제외한다.
- **입력:**
  - 좌클릭(5px 미만) = 도구 동작. 좌드래그 = 시작 층 평면에 고정한 사각 채우기.
  - 우·중 드래그 = 오빗/팬. 우클릭 단발 = 셀 삭제, Shift+클릭 = 삭제.
  - 층 올리기는 명시적 핸들로 한다. 고스트는 레이캐스트에서 제외한다. 드래그 전체가 Undo 한 단계다.
- 경사 지붕은 사각형 최상층 볼륨에만 둔다. 그 위에 셀을 올리면 평지붕이 된다는 안내를 띄우고, 옥상 prop으로 유도한다.

### 2. 문서 v3 (shared, 구현 완료)
- `RoadFeature{id, segmentId, kind: 'crosswalk' | 'speedBump', t (호 길이 비율), signal?}`, `CityDoc.features`.
  - 구간 끝에서 12m, 서로 6m 이상 떨어져야 한다.
  - 횡단보도는 보도가 필요하다. 보도가 사라지면(`segment.setType`, `roadType.upsert`) 함께 제거된다.
  - 분할은 호 길이로 재매핑한다. 이때 각 조각의 실제 길이를 쓴다.
  - `node.move`로 구간 모양이 바뀌면 같은 규칙(`pruneFeatures`, 허용오차 1e-6)으로 다시 검사한다. 규칙에 맞지 않는 시설(끝 12m, 간격 6m)은 같은 트랜잭션에서 제거한다. t 순서로 검사하고, 동률이면 id 순이다.
  - `segment.remove`는 시설도 함께 제거한다.
  - 스튜디오로 다시 열 때는 다음을 확인한다: 박공·피라미드 볼륨이 다시 변환해도 보존되는지(합쳐지면 손실로 처리), 크기 상한(`tooLarge`면 정밀 모드만 허용).
- **어린이보호구역은 구간 속성이다:** `RoadSegment.schoolZone`, `segment.setSchoolZone`. 분할하면 양쪽이 상속한다.
- `IntersectionControl.kind`에 `'allStop'`을 추가한다. `crosswalkLegs?: SegmentId[]`는 다리별 자동 횡단보도 지정이다(생략 = 보도 있는 모든 다리, `[]` = 없음). 분할·삭제 시 `replaceApproach`가 함께 갱신한다.
- `normalizeDoc`: v2 → v3에서 `features ??= {}`.

### 3. 거리 교통 시설 (sim)
- **기하:** 도로 `setback`(교차로 경계, 렌더의 아스팔트·보도·교차로 다각형)은 그대로 둔다. 교차로 횡단보도가 있는 끝에서는 그 방향 **모든 차선의 시작·끝을 횡단 구역(4m)만큼 더 자른다**(`laneStartA/B`). 그래서 횡단 구역은 항상 커넥터 영역 안에 있다. 진출 공간 계산은 바뀌지 않는다.
- **충돌 구역 예약 (ConflictZone):** 횡단보도마다 하나다. 커넥터·차선 구간과의 교차는 컴파일 시 차폭/2만큼 넓혀 계산한다.
  - **차량:** 커넥터 grant(구간 횡단보도는 요청 거리에서 받는 통과 허가)와 함께, 경로상 모든 구역을 원자적으로 예약한다. 구역에 보행자가 점유하거나 예약했거나 진입 자격(eligible)이 있는 보행자가 있으면 거부한다. 해제는 후미가 구역을 벗어날 때다.
  - **보행자:** 진입 자격이 있고 구역에 차량 예약이 0이면 구역과 건너편 대기 공간을 한 번에 예약한다. 해제는 몸체가 이탈할 때다.
  - 요청 거리(≥ 제동거리 + 5m) 안의 차량은 이미 예약했거나 정지 중이다. 따라서 "제동거리 안 커밋 차량" 앞으로 보행자가 진입할 수 없다.
- **자격:** 적색 신호에서 기다리는 보행자는 차량을 막지 않는다.
  - **신호형:** WALK 동안만 자격이 있다.
  - **비신호형:** 보행자가 우선이다. 단, 대기 차량이 있으면 보행자 연속 점유를 12초로 제한한다. 그 뒤에는 차량 1대 통과 또는 5초가 지날 때까지 신규 보행 진입을 막는다.
  - **보호구역 비신호 횡단보도:** 차량이 항상 정지선에서 완전히 정지한 뒤 진행한다.
- **보행 신호:**
  - 다리 L의 횡단보도는 L의 진입 차선이 적색이고, 녹색 위상의 **직진** 커넥터 중 L 구역을 지나는 것이 없을 때 WALK다. 그 구역을 지나는 좌·우회전은 예약 규칙으로 양보한다.
  - WALK는 7초, CLEARANCE는 ⌈L / 1.0⌉초(신규 진입 금지), 그다음 RED다.
  - 위상 녹색은 `max(green, 7 + clearance − yellow)`로 자동 연장한다.
  - 시간이 끝나도 실제 점유가 남아 있으면 차량은 계속 막힌다.
  - **구간 신호 횡단보도:** 고정 주기로 차량 녹색 30초, 황색 3초, WALK 7초 + CLEARANCE다.
- **과속방지턱:** 통과 목표 20km/h, `vAllowed(d) = sqrt(vt² + 2·b·d)`로 감속한다. 정지 장애물이 아니다.
- **보호구역:** 차선 제한속도를 min(기존, 30km/h)로 둔다. 진입 전 감속은 다음 엣지 감속 규칙을 쓴다.
- **allStop:** `d ≤ 1.5m`이고 `v < 0.15`인 상태가 10틱 이어지면 정지 완료다(`stopTick`, 접근 회차). grant는 정지 완료 순서(동률은 차량 id)다.
- **재컴파일:** 새 그래프에서 실제 차량 몸체·보행자 위치로 구역 점유를 먼저 복구한다. 그 틱에는 신규 허가를 내주지 않는다.

### 4. 시민 보행 생활 (sim 런타임, 문서 밖)
- **PedGraph:** 차량 그래프와 별도이고, 같은 최종 기하에서 파생한다.
  - 에지: 보도(차도 끝 + 보도 폭/2), 모서리(miter/bevel, 교차로 중심 통과 금지), 횡단보도, 출입구.
  - 출입구 에지는 차도를 넘지 못한다.
- **이동:** 방향별 보행 띠(0.65m)와 0.7m 간격을 지키고, 에지 전이 시 입구 공간을 확인한다. 속도는 `clamp(1.3 + 0.5(r1 − r2), 0.8, 1.8)`이고 SoA typed array로 관리한다.
- **시민:**
  - 실제 에이전트(상한 8,000명)다. 인구가 넘으면 `scale = ceil(인구 / 상한)`으로 표시만 한다. 용량 계산은 에이전트 단위다.
  - 설계 인구(`designStats`)와 시뮬 시민 수를 따로 표시한다.
  - 상태: Home, Leaving, Walking, Driving, Entering, AtWork, AtShop, Displaced. 각 상태 인원의 합 = 전체(불변식).
  - 이벤트는 `(dueTick, personId, seq)` 순서로 처리한다. 다음 일정은 실제 도착 시점부터 상대적으로 예약하고, Home 가드로 중복 출근을 막는다.
  - 출발은 해시로 분산한다. RNG 스트림은 인구 배정, 일정, 수단으로 나눈다.
- **수단:** 보행 경로가 1km 이하이면 도보다. 그 이상이면서 차량이 있으면 자가용이다: 출입구 → 도보 → 차량 스폰(personId) → 도착 → 도보 → 입장.
  - 차량이 정체로 제거되면 그 시민의 통행은 실패 처리되고 목적지에 도착한 것으로 집계한다(인원 보존).
  - 시민이 있으면 기존 수요의 주거↔직장 OD를 제거하고, 배경 교통은 임의 차선 간 통행(trafficDensity × 0.3)으로 한다.
- **버스 승객 상태머신(정원·대기열·환승)은 Phase 2c로 미룬다.**
- **경로 예산:** 틱당 차량 100건 + 보행 150건(작업 수 기준).
- **시계 (게임 결정):** `dayTime = 06:30 + 물리초 × 10`. Sol은 같은 축(배율 1)을 권고했지만, 하루를 볼 수 있어야 해서 달력 압축 모드를 택한다. 체류시간은 게임 시각, 이동은 물리 시간이다. 통계는 물리 초로 표기한다.
- **도로·건물 편집:**
  - 보행자는 반경 20m 안 같은 보도 성분으로 재투영한다. 실패하면 집으로 돌아가 Home 상태가 된다(사유 집계).
  - 집이 철거되면 시민을 제거하고 집계한다. 직장이 철거되면 귀가 후 다음 날 재배정한다.

### 5. 스냅샷 (`packages/sim/src/types.ts`)
- `pedestrians`: stride 8 = x, z, heading, speed, gaitPhase, style, state, elevation
- `pedestrianIds: Uint32Array`
- `crossings`: stride 3, `RoadGraph.crossings` 순서 = pedSignal, 보행자 수, 차량 예약 수. 정적 기하는 같은 `graphRevision`의 그래프에서 가져온다.
- `occupancy` + `buildingIds`: 실제 에이전트 수다.
- `stats.clock`, `stats.citizens`, `stats.pedestrians`.
- 새 배열은 모두 `SnapshotBuffers` 반환 풀과 transfer 목록에 넣는다. 위치가 5m 넘게 튀면 렌더러는 보간하지 않는다.

### 6. 렌더링
- **보행자:** 절차적 박스 사람 InstancedMesh 1개, `aLimb` 정점 셰이더 스윙, 그림자 없음.
- **노면:** 도로 청크에 지브라, 물린 정지선, 방지턱, 보호구역 노면을 추가한다. `segSig`에 시설, 보호구역, 노드 `crosswalkLegs`, kind를 포함한다.
- **보행 신호등:** 횡단보도 양끝에 2구 신호등.
- **창문 점등:** 설계별 InstancedMesh에 인스턴스 속성 `aOccupancy`를 두고, 낮밤 `uNight`와 곱한다.
- **HUD:** 시계와 시민 현황.

## Phase 2c로 미룸
- 버스 승객 상태머신(정원·대기열·환승)
- 보행 전용 위상(스크램블)·`SignalPhase.crossingIds`
- 운전자 준수율·단속 카메라
- 스튜디오 문맥 미리보기(필지·인접 건물)
- 동시 편집 배지
- 다각형 경사 지붕
- 셀 원본 저장
- 가중 시민의 용량 모델
- 군중 모델

## council 의견 반영
- **Astra:** 대기/자격/점유 구분, 재컴파일 시 점유 복구, 손실 판정, 시민 인원 보존, 수요 일원화, 시설 분할 → 반영. 보행 전용 위상 MVP 권고 → 동시 진행 + 원자 예약으로 대체(안전은 예약이 보장, 위상은 2c).
- **Argon:** 창문 인스턴스 속성, 차선 trim과 setback 분리, 커밋 차량, prop 범위, 보도 제거 시 횡단보도 정리, 분할 ID, allStop 판정, `segSig`, 스튜디오 입력 → 반영. 버스는 이번 단계에서 연출도 하지 않는다(2c).
