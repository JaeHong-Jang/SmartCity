- [x] server: 룸, 시퀀싱, 프레즌스, 로그+체크포인트 (장애 주입 테스트 포함)

- [x] 교차 모델 리뷰(Sol) 지적 반영: [`reviews/`](reviews/)

### Phase 1 잔여 과제
- 실제 GPU에서 성능 측정 (목표: 차량 5,000 + 건물 2,000에서 60fps) — 헤드리스 SwiftShader로는 측정 불가
- 버스 노선 오버레이를 sim 실제 경로로 표시, 자동 위상일 때도 위상 화살표 표시
- 오프라인 폴백 후 서버 재연결 시 자동 온라인 전환
- 이름 변경 시 재접속 없이 반영(프로토콜에 rename 메시지)
- 협업 e2e 간헐 실패 1회 관찰(동시 부하 상황, 재현 실패) — 추적 중

## Phase 2 — 도시 설계 심화
- 되돌리기/다시하기(사용자별, 역명령), 낙관적 적용
- 차선 변경(MOBIL), 보호 좌회전 위상, 감응 신호
- 지형 높이맵, 고가·터널, 조닝과 수요 모델(인구·일자리)
- 건물 자유 평면(다각형 압출), 승객 용량
- 성능: SoA 차량 저장소, LOD, WebGPU 평가

## Phase 3 — 돌발 상황 대응 시뮬레이션
- 서버 권위 시뮬레이션: `(seq, effectiveTick)` 명령 적용, 체크포인트(차량·RNG) 직렬화, `WebSocketSimStream`
- `incidents` 레이어: 사고(차선 차단·지속시간), 공사, 재난(구역 폐쇄), 정전(신호 소등 → 비신호 운영)
- 대응 주체: 긴급차량 출동·우선 신호(황색·전적색 보장), 우회 안내, 적응형 신호(Max-Pressure)
- 시나리오 스크립트(명령 시퀀스 + 타이밍) 재생, KPI(통행시간, 대응시간, 정체 길이, 제거 차량 수) 대시보드
- 보정·검증: 실제 교통량 데이터와 비교 (현실 예측 주장 전 필수)
